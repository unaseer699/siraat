# 6. PHASE 4 — DATA STRATEGY (Frozen v1.0)

### Planning Assumption (governs all future resource decisions)
> Lean founding team, limited capital. Data strategy must maximize trust per unit cost. Funding accelerates, never redesigns.

### Data ROI Principle
Prioritize by: User Value × Trust Impact × Acquisition Cost × Uniqueness. Highest trust/uniqueness first, not largest volume.

### MVTD — Derived, Not Guessed

**Assumptions:** 1–2 person capacity, ~40% time (2 person-days/week), 12-week window, ~3.5 hrs/society verification effort.

**Derivation:** 192 hrs ÷ 3.5 hrs ≈ 55 (theoretical ceiling) → ×0.62 execution efficiency ≈ **34 societies**

**Result: MVTD = 30–35 fully verified societies, single metro (Islamabad/Rawalpindi).**

**Standing rule:** If real effort exceeds estimates, the number flexes **down** — never cut verification quality.

### Mandatory Data Bar
No Recommendation without: Property (Tier 2 min) + NOC-verified Society (Tier 1) + ≥1 Verification with linked Evidence. Confidence must visibly degrade on thin data — never silently backfilled.

### Flywheel (closes original MVTD gap)
> More users → More verified evidence → Better recommendations → More trust → More users.

User submissions enter a **verification queue** — never auto-promoted to Fact, reviewed by the small team.

### Four Final Decisions
1. Launch deep, not wide — one metro
2. ~30–35 verified societies, not hundreds partial
3. Never trade verification quality for coverage
4. Every user interaction must improve the dataset over time
